Privacy Policy Last updated: 26 October 2026 Moto Studio is a private desktop tool used only by its owner (TikTok @omaryehiaax) on his own computer. What data it reads With the owner's permission, through each platform's official login, it reads only the owner's own accounts: YouTube (Google OAuth, read-only scopes youtube.readonly and yt-analytics.readonly): channel and video statistics and YouTube Analytics reports. Instagram (Instagram API with Instagram Login): profile, media and insights. TikTok (Login Kit): basic profile, account statistics and the list of his own public videos with their statistics. How the data is used The data is used only to analyse the owner's own content performance. It is stored only on the owner's computer. It is not sold, shared, published or sent to any third party. What it does not do It does not post, upload, comment, follow or like anything, and it does not access any other user's data. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Deleting data The owner can revoke access at any time (Google: myaccount.google.com/permissions; Instagram: Settings → Website permissions; TikTok: Settings and privacy → Security → Apps and services) and delete the local files. Contact Contact the owner through TikTok: @omaryehiaax.
